### ÁLLAMPOLGÁRI NEVELÉS — 6. OSZTÁLY *(19 óra)*

Naptári-tematikus terv az állampolgári nevelésből a «Громадянська освіта. 6–9 клас» mintatantervhez az általános középfokú oktatási intézmények számára (szerzők: Vaszilkiv I. D., Kravcsuk V. M., Tancsin I. Z.) «Ukrajna Oktatási és Tudományos Minisztériuma által ajánlott» (Ukrajna Oktatási és Tudományos Minisztériumának 2024.12.19-i № 1768 rendelete)

| № | Téma |
|---|---|
| **1.** | Bevezetés. Ismerkedés az állampolgári neveléssel. *Mi az állampolgári nevelés, és miért van rá szükség? Hogyan őrizhetjük meg és fejleszthetjük az állami értékeket? Hogyan legyünk jó állampolgárok?* |
| **I. fejezet. Az ember — a természet és a társadalom része** | |
| **2.** | Ki vagyok én? *Önismeret, egyéniség, méltóság és becsület. Érdeklődéseim és világnézetem. Óvom a természetet* |
| **3.** | Kik vagyunk mi? *Család, osztály, közösség, állam. Én otthon, az osztályban, a közösségben, az államban. Udvariasság és kölcsönös tisztelet. Az iskolai etikett alapjai* |
| **4.** | Mi vesz körül minket? *Egyetemes emberi értékek. Sokszínűség és egyenlőség. Normák és szabályok. Jogok és kötelezettségek* |
| **II. fejezet. A társadalomban élés művészete** | |
| **5–6.** | Mi a társadalom? *Hogyan hat ránk a társadalom? Hogyan hatunk mi a társadalomra? A társadalmi élet szférái: politikai, gazdasági, szociális, szellemi* |
| **7.** | Interakció a társadalomban. *Mik a jogok és kötelezettségek? Barátság, csapatmunka. Együttműködés és versengés. Hogyan tartsuk be az akadémiai tisztességet* |
| **8.** | A társadalmi viselkedés erkölcsi alapjai. *Jó és rossz. Tisztelet. Felelősség. Őszinteség. Igazságosság. Hogyan hozzunk etikai döntéseket* |
| **9.** | Tudásösszegző óra |
| **III. fejezet. Az államban élés művészete** | |
| **10–11.** | Miért van szükségük az embereknek az államra? *Mi az állam? Milyenek az állam jellemzői? Hogyan valósul meg az államhatalom? Mi a közigazgatási berendezkedés? Milyenek Ukrajna állam értékei?* |
| **12–13.** | Mit jelent állampolgársággal rendelkezni? *Az „állampolgár" fogalma a régmúltban és ma. Miben különböznek az állam állampolgárai és annak lakossága? Miért van az állampolgároknak nemcsak joguk, hanem kötelezettségük is? Milyen legyen az iskolai kollektíva állampolgári viselkedése?* |
| **IV. fejezet. A kommunikáció művészete** | |
| **14–15.** | Mi a kommunikáció? *A kommunikáció stílusai (baráti, családi, üzleti) és sajátosságaik. A kommunikáció típusai. Szavak, gesztusok, mimika. Az államnyelv szerepe a kommunikációban* |
| **16.** | Hogyan legyünk jó beszélgetőpartnerek? *Hogyan kezdjük el és tartsuk fenn a beszélgetést, hogyan fejezzük be udvariasan a beszélgetést? Hogyan mutassuk meg, hogy hallgatunk? Hogyan kérdezzünk helyesen?* |
| **17.** | Hogyan kommunikáljunk konfliktusok nélkül? *Bizalom és kölcsönös tisztelet a kommunikációban. Gyűlöletbeszéd. Saját érzelmek felismerése és kifejezése. Az empátia jelentősége a kommunikációban* |
| **18.** | Tudásösszegző óra |
| **19.** | Összegző óra |
