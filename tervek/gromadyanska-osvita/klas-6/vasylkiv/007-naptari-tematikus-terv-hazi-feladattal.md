# Naptári-tematikus terv — Állampolgári nevelés — 6. osztály (házi feladattal, Vaszilkiv)

- **Eredeti ukrán cím:** Календарно тематичне планування з Громадянської освіти 6 клас, 0,5 год на тиждень з домашнім завданням
- **Szerző:** Басараб І. В.
- **Tankönyv:** I. Vaszilkiv, V. Kravcsuk és társai tankönyve (Aszton kiadó, 2025)
- **Osztály:** 6. osztály (NUS)
- **Heti óraszám:** 0,5 óra/hét (17 óra)
- **Félév/év:** —
- **Forrás:** https://naurok.com.ua/kalendarno-tematichne-planuvannya-z-gromadyansko-osviti-6-klas-0-5-god-na-tizhden-z-domashnim-zavdannyam-519765.html

**Megjegyzések:**
- A terv a «Громадянська освіта. 6–9 клас» mintatanterv (Vaszilkiv I. D., Kravcsuk V. M., Tancsin I. Z.; az Ukrán Oktatási és Tudományos Minisztérium 2024.12.19-i № 1768-as rendelete alapján ajánlott) és a Vaszilkiv/Kravcsuk-féle tankönyv (Aszton, 2025) alapján készült.

### Naptári-tematikus terv állampolgári nevelésből a «Громадянська освіта. 6–9 клас» mintatantervhez, általános középfokú oktatási intézmények számára (szerzők: Vaszilkiv I. D., Kravcsuk V. M., Tancsin I. Z.). *„Az Ukrán Oktatási és Tudományos Minisztérium által ajánlott" (az Ukrán Oktatási és Tudományos Minisztérium 2024.12.19-i № 1768-as rendelete)*, I. Vaszilkiv, V. Kravcsuk és társai tankönyve alapján (Aszton kiadó, 2025).

### Naptári-tematikus terv (0,5 óra/hét)

| № | Dátum | Óra témája | Fő tevékenység az órán | Házi feladat |
|---|---|---|---|---|
| **1** | | Bevezetés. Ismerkedés az állampolgári neveléssel | Megbeszélés: mit tanul a tantárgy. Munka a fogalmakkal: állampolgár, egyenlőség, kötelezettség | Feldolgozni az 1. §-t, leírni 3 tulajdonságát az igazi állampolgárnak |
| **2** | | Ki vagyok én? Önismeret és egyéniség | „Az én arcképem" gyakorlat. A fogalmak megbeszélése: méltóság, becsület, önismeret | Feldolgozni a 2. §-t, előkészíteni egy elbeszélést a hobbijaimról |
| **3** | | Kik vagyunk mi? Az ember a közösségben | Csoportmunka: az osztály közös értékeinek meghatározása. A fogalmak elemzése: sokszínűség és tisztelet | Feldolgozni a 3. §-t, találni egy példát sikeres közösségre |
| **4** | | Mi van körülöttünk? Az ember és a természet | Vita az ökológiai felelősségről és a fenntartható fejlődésről | Feldolgozni a 4. §-t, összeállítani a „Családom öko-szokásai" tervet |
| **5** | | **1. gyakorlati munka:** Esszé „Az én szerepem állampolgárként az állam megerősítésében" | Esszé írása vagy séma készítése „A jogok és kötelezettségek összefüggése" | Ismételni az I. fejezet anyagát |
| **6** | | Az ismeretek összegzése az „Az ember — a természet és a társadalom része" témából | Tesztelés vagy vetélkedő a rögzítő feladatok alapján (39. o.) | Elkezdeni az ismerkedést a II. fejezettel |
| **7** | | Mi a társadalom és az interakció benne | Társadalmi interakciós helyzetek modellezése. A „társadalom" fogalmának feldolgozása | Feldolgozni az 5–6. §-t |
| **8** | | A viselkedés erkölcsi alapjai | Élethelyzetek elemzése az erkölcs és az etika szemszögéből | Feldolgozni a 7. §-t. Felkészülés a tesztelésre |
| **9** | | Miért van szükségük az embereknek államra? | Munka illusztrációkkal: az állam funkciói. A törvények jelentőségének megbeszélése | Feldolgozni a 8. §-t |
| **10** | | Mit jelent állampolgársággal rendelkezni? | Ismerkedés a dokumentumokkal (útlevél, anyakönyvi kivonat). A jogok és kötelezettségek megbeszélése | Feldolgozni a 9. §-t |
| **11** | | **2. gyakorlati munka:** Helyi kezdeményezések kutatása a közösségben | Példák keresése és leírása a város/falu lakosainak aktív álláspontjára | Ismételni a III. fejezetet |
| **12** | | Az ismeretek összegzése: „Az államban való élet művészete" | A rögzítő feladatok elvégzése (90. o.). Tematikus beszámoló | Elkezdeni a IV. fejezetet |
| **13** | | Mi a kommunikáció? A kommunikáció stílusai | „Telefon" gyakorlat: információátadás. Ismerkedés a fogalmakkal: mimika, gesztusok, bizalom | Feldolgozni a 10. §-t, megfigyelni az emberek gesztusait |
| **14** | | Az államnyelv mint az egység tényezője | Az ukrán nyelv kommunikációban és államépítésben betöltött szerepének megbeszélése | Előkészíteni egy üzenetet az államnyelv fontosságáról |
| **15** | | Hogyan legyünk jó beszélgetőpartnerek? A kérdezés művészete | Szerepjáték: párbeszéd az udvariasság és a kérdések világosságának szabályainak betartásával | Feldolgozni a 11. §-t, összeállítani 5 „udvarias kérdést" |
| **16** | | Konfliktusmentes kommunikáció. Empátia | Praktikum: „Hogyan értsük meg a másikat?" Az empátia összetevőinek elemzése | Feldolgozni a 12. §-t, összeállítani a cselekvések listáját az osztálybeli kapcsolatok javítására |
| **17** | | Összegző óra. Állampolgári kompetencia | Mini-projektek bemutatása. Összegző tesztelés a IV. fejezetből | Ismételni a tankönyv szótárának fő fogalmait |
