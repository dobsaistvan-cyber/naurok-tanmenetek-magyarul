# Naptári-tematikus terv angol nyelvből 4. osztály számára (105 óra, heti 3 óra)

- **Eredeti ukrán cím:** Календарно-тематичний план з англійської мови для 4 класу (105 годин, 3 години в тиждень)
- **Szerző:** nem szerepel az oldalon
- **Tankönyv:** Англійська мова: підруч. для 4 кл. закл. загал. серед. освіти (з аудіосупроводом) / С. С. Губарєва, О. М. Павліченко. — Харків: Вид-во «Ранок», 2021. — 144 с.: іл.
- **Osztály:** 4. osztály
- **Heti óraszám:** 3 óra (évi 105 óra)
- **Félév/év:** teljes tanév
- **Forrás URL:** https://naurok.com.ua/kalendarno-tematichniy-plan-z-angliysko-movi-dlya-4-klasu-105-godin-3-godini-v-tizhden-356251.html

> Megjegyzés: a terv a Szavcsenko O. Ja. vezetésével kidolgozott tipikus oktatási program (3–4. osztály, Ukrajna Oktatási és Tudományos Minisztériumának 2022.08.12-i 743-22. sz. rendelete által jóváhagyva) alapján készült.
