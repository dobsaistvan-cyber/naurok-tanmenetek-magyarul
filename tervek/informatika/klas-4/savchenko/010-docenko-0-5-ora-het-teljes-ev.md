# Naptári-tematikus terv informatikaórákhoz elvárt tanulási eredményekkel, 4. osztály (NUS), teljes év

- **Eredeti ukrán cím:** Календарно-тематичне планування уроків інформатики з очікуваними результатами навчання (17 год на рік) для здобувача освіти 4 класу за програмою О. Я. Савченко
- **Szerző:** Доценко Н.
- **Tankönyv:** nincs megadva a forrásban; О. Я. Савченко programja
- **Osztály:** 4. osztály (NUS)
- **Heti óraszám:** 0,5 óra
- **Félév/év:** teljes év (17 óra)
- **Forrás URL:** https://naurok.com.ua/kalendarno-tematichne-planuvannya-urokiv-informatiki-z-ochikuvanimi-rezultatami-navchannya-17-god-na-rik-dlya-zdobuvacha-osviti-4-klasu-za-programoyu-o-ya-savchenko-416870.html
- **Megjegyzés:** Egy tanuló számára készült terv (17 óra/év). A táblázat fejléce a forrásban többször megismétlődik (oldaltörések miatt); a fordításban egyszer szerepel. Több óránál számozatlan altémák szerepelnek (1., 9., 11., 12., 13., 14. óra). A dátumok üresek. A 4. óra témájában a „збереження" kétszer szerepel („bevitel, megőrzés, feldolgozás, megőrzés vagy adatok kivitele"). Kódolási hiba: „конк��етних" (13. óra). Elválasztási kötőjelek a forrásban („інфор-маційних", „достовір-ність" stb.) — a fordításban teljes szavakkal.
