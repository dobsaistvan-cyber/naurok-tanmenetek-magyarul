# Módosított program a Felfedezem a világot tantárgyból sajátos nevelési igényű (ООП) gyermekek számára, 4. osztály, II. félév

- **Megjegyzés:** Módosított program ООП tanuló számára (Гридасов Андрій; IV. támogatási szint; nehézségkategória: értelmi fejlődés) — a tanuló neve a nyilvános forrásdokumentum fejlécének része. A program a Sijan-féle mintatanterv alapján készült. Jóváhagyta: a Volodimirivszkij Líceum igazgatónője, Olena Mitrofanova (2025, a dátum üresen maradt). Minden témához több dátum tartozik (az egy témára eső órák száma 1–5). Dátumok 13.01.–30.05., évszám nélkül (a hétköznapok mintázata a 2025-ös naptárnak felel meg); tavaszi szünet 24–28.03. Elírások a forrásban: „Космосмічна станція" (8. téma); „вертуальна подоож" (46. téma); „ємоційний / ємоції" (27., 41. téma); „пограми" (fejléc); „вирів" (4., 29. téma); „жестам и" (6. téma); „родине дерево" (9. téma); „їм'я" (42. téma); „мріє" (41. téma); „мишення" (28. téma, valószínűleg „мишеня" — egérke). A 3. téma várt eredménye félbeszakad a forrásban („наводить приклади дій,"). A 24. és a 26. téma várt eredményei azonosak.
