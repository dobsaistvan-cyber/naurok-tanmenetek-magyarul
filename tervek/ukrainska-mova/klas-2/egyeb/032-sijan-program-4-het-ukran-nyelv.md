# Heti terv — Ukrán nyelv, 2. osztály (NUS), 4. hét, Sijan-program

- **Eredeti ukrán cím:** Календарне планування для учнів 2 класу.(За програмою Р.Шияна НУШ ІІІ тиждень)
- **Szerző:** Чеглатонєва О. В.
- **Tankönyv:** Nincs megnevezve (Sijan-program, Р. Шиян)
- **Osztály:** 2. osztály (NUS)
- **Heti óraszám:** 5 óra (a héten)
- **Félév/év:** 4. hét, 2023. szeptember 18–22. (a dátumok év nélkül szerepelnek; a 4. hét témája: «Változások»)
- **Forrás:** https://naurok.com.ua/kalendarne-planuvannya-dlya-uchniv-2-klasu-za-programoyu-r-shiyana-nush-iii-tizhden-463423.html
- **Megjegyzés:** **A cím téves:** a cím «ІІІ тиждень» (3. hét), de a leírásban «ІV тиждень» (4. hét) szerepel, és a táblázat is a 4. hetet tartalmazza («Тиждень 4. «Зміни»»). A forrás egy többtantárgyas heti terv (Felfedezem a világot, ukrán nyelv, matematika, művészet, testnevelés) — ebből csak az ukrán nyelv órák (12–16. óra) kerültek lefordításra, a többi tantárgy részei nem. A terv a fájl előnézetében (Перегляд файлу) jelenik meg. Forráshiba: «Вівторок19.09» (hiányzó szóköz).
