## Naptári terv

**TECHNOLÓGIÁK**

***(heti 1 óra)***

| № | ***Az óra témája*** | ***Dátum*** |
| --- | --- | --- |
| **1.** | ***Kígyócska-okoska.*** A munkahely megszervezésének szabályai az órán. A munkához szükséges anyagok, eszközök és segédeszközök. Könyvjelző készítése. |  |
| 2. | ***Vidám szünet.*** Munka papírral. „Vidám békácska" játék készítése (minta alapján). |  |
| 3. | ***Séta az esőben.*** Tépett papírdarabokból készült applikáció. Mozaik. Az esernyő díszítése mozaik segítségével. |  |
| 4. | ***Sünike – száz tűcske.*** Tépett papírdarabokból készült applikáció. „Sünike" applikáció létrehozása. |  |
| 5. | ***„Fogj, halacska...".*** Munka természetes anyagokkal. A természetes anyagok előkészítése a munkához. Levélapplikáció létrehozása. |  |
| 6. | ***Törölköző.*** Kép felvitele papírra sablon segítségével. A sablon segítségével megjelölt legegyszerűbb formák kivágása. „Törölköző" applikáció létrehozása (minta alapján). |  |
| 7. | ***Színes nyalóka.*** Munka gyurmával. A gyurma megmunkálásához való eszközök és segédeszközök. Biztonságos munkafogások. Nyalóka készítése gyurmából. |  |
| 8. | ***Broniszláv robot.*** Munka papírral. Robot készítése minta alapján. |  |
| 9. | ***Csoda-Judo Hal-bálna.*** A papír hajtogatása és összehajtása. Megismerkedés az origami technikával (általános elképzelés). A legegyszerűbb origami termékek létrehozása. |  |
| **10.** | ***Ujjbábszínház.*** Munka papírral. „Ujjbábszínház" játék készítése. |  |
| 11. | ***Ruha a mackóknak.*** Dizájner. Papírruhák modellezése mackóknak. A létrehozott ruhák díszítése. |  |
| 12. | ***Jeges répa.*** Térbeli papírtermékek. Jégcsap létrehozása (minta alapján). |  |
| 13. | ***„Hull, hull a hó...".*** A cselekvések sorrendje az applikációk létrehozása során. Téli kompozíció készítése. |  |
| 14. | ***Földönkívüli látogatása.*** A cselekvések sorrendje az applikációk létrehozása során. „Földönkívüli űrhajó" applikáció létrehozása (minta alapján). |  |
| 15. | ***Vidám csiga.*** A papírtermékek díszítése. Valentin-napi üdvözlőlap készítése (minta alapján). |  |
| 16. | ***Hamarosan ünnep – Újév.*** Papírdíszek. A papírtermékek díszítése. Újévi játékok készítése papírból. |  |
