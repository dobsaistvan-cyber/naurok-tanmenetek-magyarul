# Naptári terv képzőművészetből az 1. osztály számára (I. félév)

- **Eredeti ukrán cím:** Календарне планування з образотворчого мистецтва
- **Szerző:** Гуменюк А. М.
- **Tankönyv:** nem nevesíti a forrás (a tartalom és az oldalszámok a Kalinicsenko–Arisztova 1. osztályos tankönyvet követik)
- **Osztály:** 1. osztály (NUS)
- **Heti óraszám:** 1 óra (I. félév: 16 óra)
- **Félév/év:** I. félév (évszám a forrásban nincs megadva; a tétel 2026. szeptember 8-án jelent meg)
- **Forrás URL:** https://naurok.com.ua/kalendarne-planuvannya-z-obrazotvorchogo-mistectva-530573.html
- **Megjegyzés:** A sorszám és a dátum oszlop üres a forrásban — a számozás sorrend alapján. Csak az I. félév 16 órája jelenik meg (6–63. o.). Elírások a forrásban: „*Перег* ***ляд:*** мультфільм «Незнайко в Сонячному місті»" („Перегляд" kettészakadva); „***Краса рідної*** *землі*" (a cím két részre szakadva, eltérő formázással); „***Веселковий диво грай.***" („дивограй" helyett „диво грай"); „Ознайомлення зі кольорами веселки" („з кольорами" helyett „зі кольорами"); „Малювання диво - машини" (szóközök a kötőjel körül); „(с. 30- 31)." (szóköz a kötőjel után).

## KÉPZŐMŰVÉSZET

*(heti 1 óra)*

| № | Az óra témája | Dátum |
|---|---|---|
| 1 | **Első alkalommal az első osztályban.** A munkahely megszervezése. Anyagok és eszközök, amelyekkel a művészek dolgoznak. A pont, a vonal mint a képek megalkotásának eszközei. Különböző jellegű vonal-képek készítése: iskolai csengő vagy hátizsák rajzolása *(filctoll) (6–7. o.).* |  |
| 2 | **A barátaim.** Vonalak: egyenes, tört, görbe. Ajándék rajzolása a barátnak (barátnőnek) különböző vonalak segítségével *(filctoll vagy színes ceruza) (10–11. o.).* |  |
| 3 | **A környezetem.** Kontúr. Rajzolás különböző vonalakkal *(filctoll vagy színes ceruza).* Mese összeállítása rajzsorozat alapján *(14–15. o.).* |  |
| 4 | **A világ körülötted.** A rajz elhelyezése a papírlapon. Egyszerű formájú tárgyak készítése. „Virágos tisztás" kompozíció rajzolása *(gouache, akvarell) (18–19. o.).* |  |
| 5 | **A babavilágom.** Hangulat a művészeti alkotásokban. Megtekintés: „Nemtomka Napvárosban" rajzfilm (részlet). „Ünnepi tűzijáték a babavárosban" vagy „Utazás a városban" kompozíció rajzolása *(viaszceruza, akvarellfesték) (22–23. o.).* |  |
| 6 | **Gyermeki hobbik.** Forma. Megtekintés: „Lip repülőgép" rajzfilm (N. Vovk meséi alapján). Csodagép rajzolása különböző formák felhasználásával *(színes ceruza) (26–27. o.).* |  |
| 7 | **Őszi vásár.** Az ollóval való munka szabályai. Applikáció. A lap síkjának kitöltése sziluettképekkel. „Termés" applikáció készítése *(színes papír) (30–31. o.).* |  |
| 8 | **Az én Ukrajnám gazdag és vendégszerető.** Munka természetes anyagokkal. A gyurmával való munka szabályai. Mesebeli szereplők mintázása *(gyurma, természetes anyagok) (34–35. o.).* |  |
| 9 | **Szülőföldem szépsége.** Színek: alapszínek és származtatott színek. Paletta. A származtatott színek képzésének módjai. A természet ábrázolása foltok szétfújásával („Színes pillangók") *(festék, színezett papír, szívószál) (38–39. o.).* |  |
| 10 | **Szivárványos csodajáték.** Ismerkedés a szivárvány színeivel (spektrális színek) és sorrendjükkel. A lap síkjának kitöltése képpel. „A szivárvány színei" kompozíció készítése *(akvarellfesték) (42–43. o.).* |  |
| 11 | **Különböző színek a természetben.** Színek: meleg és hideg. „Ház az Ősznek" vagy „A Tél jégkunyhója" kompozíció készítése *(akvarellfesték) (46–47. o.).* |  |
| 12 | **Téli ritmusok.** Ritmus. Kollektív munka: hópelyhek kivágása papírból, dísz készítése a hópelyhekből meghatározott ritmusban *(fehér papír, karton) (50–51. o.).* |  |
| 13 | **Ünnepi átváltozások.** Színek: világos és sötét. A spektrális színek világosítása és tompítása; színárnyalatok. Vicces hóember rajzolása *(gouache).* „A hóemberek tánca" kompozíció kollektív készítése *(54–55. o.).* |  |
| 14 | **Téli ünnepek.** Próbáld meg lerajzolni az újévi szépséget ujjlenyomatokkal. Tanulj meg sorrendben fenyőfát ábrázolni. „Újévi fenyőfa" kompozíció készítése *(58–59. o.).* |  |
| 15 | **Örüljetek! Jön az ünnep!** Karácsonyi képeslap készítése *(színes karton, színes papír) (62–63. o.).* |  |
| 16 | **Ellenőrizd magad!** A tanulók ismereteinek összegzése és rendszerezése. Kollektív munka készítése. |  |
