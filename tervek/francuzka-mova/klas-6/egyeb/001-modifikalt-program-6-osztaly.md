# Módosított program francia nyelvből a 6. osztályos tanuló számára (2. tanulási év)

- **Eredeti ukrán cím:** Модифікована програма з французької мови для учнів 6-го класу (другій рік навчання)
- **Szerző:** Ірина Лопатюк (összeállító)
- **Tankönyv:** nincs megadva
- **Osztály:** 6. (NUS)
- **Heti óraszám:** 2 óra (összesen 68 óra)
- **Félév/év:** teljes tanév (a forrásban nincs megadva a tanév; a tétel megjelenése: 2025.05.22.)
- **Forrás URL:** https://naurok.com.ua/modifikovana-programa-z-francuzko-movi-dlya-uchniv-6-go-klasu-drugiy-rik-navchannya-472160.html
- **Megjegyzés:** Módosított program egy sajátos nevelési igényű (ООП) 6. osztályos tanuló számára (4. támogatási szint, súlyos fokú tanulási nehézségek), a «Іноземна мова. 5–9 класи» modell tanterv (szerzők: Redko V. G., Shalenko O. P., Sotnikova S. I., Kovalenko O. Ja., Koropecka I. B., Jakob O. M., Samojljukevics I. V., Dobra O. M., Kior T. M.) alapján. A francia a második idegen nyelv. A témák óraszámainak összege (11+11+12+8+8+10+8) megegyezik a megadott 68 órával. Forráshibák [sic] jelöléssel: «другій рік навчання» (другий); «обмінюватись … з іншим учасниками» (іншими — többször); «з находити» / «з находить» (знаходити / знаходить, 7. téma); «зі навчальною допомогою» (з навчальною, 7. téma); «вчителя;;» (kettős pontosvessző, 3. téma); «занотов��є» (olvashatatlan karakter — feltehetően «занотовує», 6. téma); «Масляна» (az ukrán «Масниця» helyett, 4. téma); a 4. téma elvárt eredményeinél «предмети в школі» szerepel (a téli ünnepek helyett — feltehetően átmásolt hiba az 5. témából).

**egy sajátos nevelési igényű 6. osztályos tanuló számára (második tanulási év)**
