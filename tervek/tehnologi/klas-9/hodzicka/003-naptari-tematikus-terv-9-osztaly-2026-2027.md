## Naptári-tematikus terv technológiából a 2026–2027-es tanévre, 9. osztály NUS

**(35 óra — heti 1 óra)**

**A terv a «Technológiák. 7–9. osztály» modellprogramnak megfelelően készült** az általános középfokú oktatási intézmények számára (szerzők: Ходзицька І. Ю., Горобець О. В., Медвідь О. Ю., Пасічна Т. С., Приходько Ю. М.)

| **1. MODUL** |  |  | **«POLIMER AGYAG KIEGÉSZÍTŐ» (9 óra)** |  |  |
| 1 |  |  | Bevezetés. A munkahely megszervezése és a biztonsági szabályok a polimer agyaggal való munkánál. A kreatív projektek bemutatása. | Tudatosítja a biztonságos munkavégzés jelentőségét; elemzi a jövőbeli termékkel szembeni követelményeket; kutatja az anyag tulajdonságait **(ГР1, ГР2)**. | Készítsd el a jövőbeli kiegészítő (bross, medál vagy kulcstartó) vázlatait, gyűjts ötletgyűjteményt. |
| 2 |  |  | Ötletkeresés és vázlatkészítés. A trendek és a színskála kutatása. | Kiválasztja a termék optimális változatát; vázlatot készít az arányok és a színharmónia figyelembevételével **(ГР1, ГР2)**. | Készítsd elő a szükséges anyagokat és eszközöket (polimer agyag, munkafelület, mintázóeszköz). |
| 3 |  |  | Megmunkálási technológiák: az anyag előkészítése, gyúrás, a színek keverése és az árnyalatok átmenete (gradiens). | Ismeri az anyag munkához való előkészítésének fogásait; alkalmazza a színkeverés és a gradiens technikáit **(ГР2, ГР3)**. | Gondold át a textúra vagy a minta részleteit a munka következő szakaszához. |
| 4 |  |  | Formaalkotás: «mica shift», «kaleidoszkóp» technikák vagy textúrás elemek készítése. | Elvégzi a termék formaalkotását a választott kézi plasztika technikájával **(ГР2, ГР3)**. | Dolgozd ki otthon a jövőbeli termék egyes díszítőelemeit (igény szerint). |
| 5 |  |  | Gyakorlat: a kiegészítő összetett, többkomponensű részleteinek létrehozása. | Önállóan kombinálja az elemeket, térbeli szerkezetet alakít ki a polimer agyag termékből **(ГР2, ГР3)**. | Ellenőrizd a részletek illesztésének minőségét, készítsd elő a felületet a kiégetéshez. |
| 6 |  |  | Végső megmunkálás a kiégetés vagy szárítás előtt. A hibák kiküszöbölése. | Ellenőrzi a termék felületének minőségét; feltárja és kiküszöböli az apró hibákat a hőkezelés előtt **(ГР2, ГР3)**. | Készítsd elő a kiégetés alapját (tapadásmentes felület, tepsi). |
| 7 |  |  | Hőkezelés (kiégetés/szárítás) a gyártó utasítása szerint. Biztonsági szabályok. | Betartja a biztonsági szabályokat a polimer agyag hőkezelése során, felügyelet mellett **(ГР1, ГР2)**. | Készítsd elő a csiszoláshoz szükséges anyagokat és a kiegészítőket. |
| 8 |  |  | Csiszolás, polírozás és lakkozás. A kiegészítők (rögzítők, láncok) felszerelése. | Elvégzi a termék végső díszítését; gondosan felszereli a kiegészítőket a szerkezetnek megfelelően **(ГР2, ГР3)**. | Készítsd elő terméked rövid bemutató-elbeszélését a projekt védéséhez. |
| 9 |  |  | A projekt bemutatása és védése. A termék minőségének értékelése. | Bemutatja a kész kiegészítőt; érvel a dizájn választása mellett; önértékelést végez **(ГР1, ГР3, ГР4)**. | Elemezd a polimer agyaggal való munka tapasztalatait, készíts ötleteket a következő modulhoz. |
| **2. MODUL** |  |  | **«ÖKOGYERTYATARTÓ» (9 óra)** |  |  |
| 10 |  |  | Bevezetés a modulba. Az ökodizájn jelentősége a modern belső térben. Munkavédelem. | Megérti az ökodizájn és az újrahasznosítás koncepcióját; betartja a biztonsági szabályokat a munka során **(ГР1, ГР2)**. | Gyűjts ökológiai és természetes anyagokat a gyertyatartó készítéséhez (gallyak, tobozok, kávészemek stb.). |
| 11 |  |  | Tervezés és vázlatkészítés. A gyertyatartó szerkezeti sémájának kiválasztása. | Kidolgozza az ökogyertyatartó vázlatát; kiválasztja az alapot és harmonikusan kombinálja a természetes anyagokat **(ГР1, ГР2)**. | Készítsd elő az alapot (fakorong, üvegedény vagy gipszforma) és az eszközöket (ragasztópisztoly). |
| 12 |  |  | Az alapokkal való munka technológiái (fakorongok, gipsz vagy üvegedény). | Ismeri a választott alap előkészítésének és elsődleges megmunkálásának fogásait **(ГР2, ГР3)**. | Válassz dekorációt a gyertyatartó alapjára való rögzítéshez. |
| 13 |  |  | Természetes anyagokkal való díszítés: tobozok, moha, gallymetszetek, kávészemek, zsineg. | Gyakorlatilag megvalósítja a projekt elképzelését, megbízhatóan és esztétikusan rögzíti a díszítőelemeket **(ГР2, ГР3)**. | Gondold át a rögzítés közbenső szakaszait és a termék védőbevonatát. |
| 14 |  |  | Gyakorlat: az ökogyertyatartó összeállítása és kompozíciós kialakítása. | Elvégzi a dekorelemek teljes összeállítását, betartva az esztétikát és a szimmetriát **(ГР2, ГР3)**. | Készítsd elő a termék védőkezeléséhez szükséges anyagokat. |
| 15 |  |  | A fa megmunkálásának / védőbevonatának technikái (alapozás, vízbázisú lakk). | Védőbevonatokat alkalmaz a termék tartóssága érdekében; betartja a technológiai követelményeket **(ГР2, ГР3)**. | Készíts biztonságos vagy LED-gyertyát a teszteléshez. |
| 16 |  |  | Tűzbiztonsági és funkcionalitási ellenőrzés. | Teszteli a terméket stabilitásra, funkcionalitásra és a biztonsági követelmények betartására **(ГР2, ГР4)**. | Készíts reklámszlogent vagy mini-bemutatót az ökogyertyatartóról. |
| 17 |  |  | Minimarketing: az ökogyertyatartó bemutatása és saját projekt értékelése. | Bemutatja az ökogyertyatartót; értékeli a projekt ökológiai értékét és kivitelezési minőségét **(ГР1, ГР3, ГР4)**. | Gyűjts ötleteket és anyagokat a következő modulhoz («Dísztányér»). |

| **3. MODUL** |  |  | **«DÍSZTÁNYÉR» (9 óra)** |  |  |
| 18 |  |  | A dísztányér szerepe a belső térben. A mesterség története és a modern technikák. | Kutatja az edénydíszítés történelmi és modern tendenciáit; kiválasztja a díszítés stílusát **(ГР1, ГР2)**. | Készítsd elő a díszítés alapját (kerámia-, üveg- vagy rétegeltlemez-tányért) és a rajz vázlatát. |
| 19 |  |  | Az alap anyagának kiválasztása és a vázlat kidolgozása. A kompozíció átvitele a felületre. | Átviszi a vázlatot a tányér felületére a kompozíciós törvények figyelembevételével **(ГР1, ГР2)**. | Készítsd elő a festékeket (akril), kontúrokat, ecseteket vagy a dekupázs technikához szükséges anyagokat. |
| 20 |  |  | A felület előkészítése: zsírtalanítás, alapozás (szükség esetén). | Technológiai műveleteket végez a felület előkészítésére a jó tapadás biztosítása érdekében **(ГР2, ГР3)**. | Gondold át a színskálát az alapszínréteghez. |
| 21 |  |  | A kontúrok és a festmény/dekor alapelemeinek felvitele. | Ismeri a kontúrpaszta- és festékhasználat készségeit; elvégzi a fő elemeket **(ГР2, ГР3)**. | Folytasd otthon a kompozíció részletein való munkát (szükség esetén). |
| 22 |  |  | Részletezés és a felület művészi kialakítása. | Elvégzi az apró részletek kidolgozását, kifejezővé és egységessé teszi a kompozíciót **(ГР2, ГР3)**. | Készítsd elő a második réteghez vagy a rajz javításához szükséges anyagokat. |
| 23 |  |  | Gyakorlat: a festmény művészi befejezése és a pontatlanságok kiküszöbölése. | Javítja a színátmeneteket, eléri a díszítőbevonat rendezett megjelenését **(ГР2, ГР3)**. | Készítsd elő a védő lakkanyagokat. |
| 24 |  |  | Az eredmény rögzítése: lakkozás vagy hőkezeléses kiégetés (a festék típusának megfelelően). | Betartja a díszítőréteg rögzítésének technológiáját a termék védelme érdekében **(ГР2, ГР3)**. | Készítsd elő a falra való rögzítéshez szükséges elemet vagy egy stabil állványt. |
| 25 |  |  | Rögzítő vagy állvány készítése a dísztányérhoz. | Megkonstruál és felszerel megbízható rögzítőt vagy állványt a termék bemutatásához **(ГР2, ГР3)**. | Készítsd el a dísztányéron végzett munkáról szóló beszámolót. |
| 26 |  |  | A projektek védése. A tanulói munkák kiállítása. | Bemutatja a kész tányért; részt vesz az osztálytársak munkáinak megbeszélésében és értékelésében **(ГР1, ГР3, ГР4)**. | Készítsd elő az ötleteket és anyagokat a kézimunka-szervező elkészítéséhez. |
