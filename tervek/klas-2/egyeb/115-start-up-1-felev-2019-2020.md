# Naptári-tematikus terv a Start Up tankönyvhöz, 2. osztály, I. félév, 2019–2020-as tanév

- **Eredeti ukrán cím:** КТП до підручника start up 2 клас
- **Szerző:** Дмитрик В. С.
- **Tankönyv:** Start Up, 2. osztály
- **Osztály:** 2. osztály
- **Heti óraszám:** 3 óra (15 tanítási hét, 45 óra)
- **Félév/év:** I. félév, 2019–2020-as tanév
- **Forrás URL:** https://naurok.com.ua/ktp-do-pidruchnika-start-up-2-klas-120399.html

> Megjegyzés: a terv 15 tanítási hétre (45 órára) készült az I. félévre. A forrás táblázat oszlopai (hallás utáni értés, olvasás, beszéd, írás) a megjelenítésben összeolvadtak; a gyakorlatok több készségnél ismétlődnek, ezért óránként egybeszerkesztve szerepelnek. A dátumok a forrásban üresek. A 16. óránál a forrás elütése ("розд.маеріал") javítva szerepel.
