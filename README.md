# Naurok Tanmenetek Magyarul

Tanársegéd gyűjtemény magyar nyelvű tanároknak: a
[naurok.com.ua](https://naurok.com.ua/biblioteka/angliyska-mova) angol
tanmenetei (Планування, typ-5), 1–11. osztály, egy-az-egyben magyar
fordításban.

- **1620 tétel**, **1598 letölthető terv** (Markdown-fájl)
- **22 hiányzó tétel**: a forráson csak regisztrációhoz kötött letölthető
  fájlként érhető el, megjelenített szöveg nélkül — ezért nem fordítható,
  és kitalált tartalommal nem pótoltuk. Az oldalon külön jelölve szerepel,
  eredeti címmel és forráslinkkel.
- Az angol óracímek angolul maradtak; a szerzők neve eredeti ukrán
  írásmóddal szerepel.

Az oldal GitHub Pages-en fut: nyisd meg, keress, szűrj évfolyam,
tankönyv, félév és óraszám szerint, és töltsd le a terveket egy kattintással.

A tervek szerzői joga az eredeti szerzőket illeti; a gyűjtemény a
Naurok könyvtárában megjelenített szövegek magyar fordítása.
